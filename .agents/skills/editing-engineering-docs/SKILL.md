---
name: editing-engineering-docs
description: Edits technical drafts for a reader completing a procedure, looking up a contract, or deciding between alternatives.
---

Identify what the reader is here to do. For a procedure, put prerequisites before the first command and an observable success condition after it. For reference, lead with the contract and its exceptions. For a decision, lead with the recommendation and the condition that would reverse it.

Replace promotional adjectives with observable behavior; if no evidence supports the claim, cut it. Keep the same noun for the same object, preserve uncertainty and version limits, and check examples against the actual interface. Return the revised draft, not a list of prose rules.
