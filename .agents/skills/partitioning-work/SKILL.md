---
name: partitioning-work
description: Partitions a requested swarm or parallel investigation into independent assignments with an integration check.
---

Before fan-out, name the result the pieces must produce together. Split by non-overlapping writable paths or by distinct read-only questions. Keep dependent steps with one owner. If the split requires two writers in the same file or one worker needs the other’s answer first, handle that part serially.

Give each Task worker its scope, the starting evidence, and the check or finding to return. For measurements, specify the same revision, input and unit. Aggregate by question, resolve conflicting claims against the source, and run the combined check in the checkout containing the edits. Report gaps rather than counting worker completions as verification.
